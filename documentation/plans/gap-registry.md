# Gap Registry — Open items, owners, evidence, exit criteria

> All paths in this document are relative to the repository root. For example,
> `source/reforge/game_core/src/movement.rs` means the path below the repository
> root, not an absolute filesystem path.

> Live successor of `documentation/history/plans/server-side-gap-2026-08-15.md`
> and `documentation/history/plans/gap-analysis-2026-08-15.md`; both historical
> files are read-only. `documentation/progress.md` keeps the short checklist;
> this file owns per-item detail: owner, state, evidence, dependency, risk, and
> exit criterion.

## How to use

- One row represents one independently closable gap. When a gap closes, keep its
  row with state `CLOSED` in [Closed this block](#closed-this-block).
- State values are `OPEN`, `IN PROGRESS`, `BLOCKED`, and `CLOSED`.
- Evidence is checked against baseline `96606e3` plus the uncommitted changes in this slice unless a commit is named.
- Priorities: P0 blocks the user goal, P1 blocks deployment or progression, P2
  is visible gameplay/content, and P3 is hygiene or test debt.

## Evidence boundary: frozen C++ oracle

`source/server/` is local-only evidence for the frozen C++ parity oracle. ADR-0012
keeps that oracle in the on-demand WSL environment; the path is intentionally
ignored by Git in [`.gitignore`](../../.gitignore#L53-L55) and is not restored by
GitHub CI. References to `source/server/...` are therefore not reproducibility
requirements for GitHub CI. CI validates versioned files and versioned Markdown
links only; the runbook/local parity check validates oracle references locally.
Never copy the frozen C++ source into this repository. See [ADR-0012](../adr/0012-windows-native-runtime-wsl-on-demand.md).
